# Session Checklist

1. Verify requirements, public API stability and ownership behavior.
2. Review diff for unrelated edits, generated files, vendor changes and dead code.
3. Run relevant tests, formatting, static checks and both build systems when relevant.
4. Explain untested platforms and toolchain limits.
5. Summarize files changed, validation performed and residual risks.
