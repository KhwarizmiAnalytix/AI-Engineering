# AI-Engineering agent contract

Do not invent what project rules say. Check the target repository's local instructions and API first. `src/ai_engineering/rules/` contains baseline conventions; `src/ai_engineering/profiles/` identifies contextual guidance, not overrides. For a task, read only relevant skills in `src/ai_engineering/skills/`. Never modify an unrelated repository or vendor dependencies without explicit scope. Cite the tests actually executed and report missing toolchains and unverified claims.
